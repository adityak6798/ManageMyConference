# ADR-003: Harness-first delivery

Status: accepted | Owner: engineering | Date: 2026-08-09

## Decision

Complete the context graph, enforcement, CI, and executable reference slice before parallel feature work. The repository is a discoverable prompt-routing system, not a thin instruction file plus hidden tribal knowledge.

## Consequences

Feature agents receive bounded context and hard feedback. Readiness is finite and demonstrated by the reference slice; documentation alone cannot satisfy the gate.
