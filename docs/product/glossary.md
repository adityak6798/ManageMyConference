# Glossary

Status: canonical | Owner: product | Last verified: 2026-08-09

- Abstract/submission: an applicant's response to a CFP.
- Content/session: accepted or independently created program content.
- Evaluation plan: criteria and scales applied by reviewers.
- Published projection: explicitly public, sanitized representation of canonical records.
- Speaker: an event-scoped participant attached to content.
- Prospect: CRM person not yet converted into an event speaker.
- Delivery attempt: immutable record of an outbound message or projection try.
- Fake adapter: deterministic local/CI implementation of an external provider port.
